设计总结

Cross-module Design Guidelines

统一视觉语言

✓

深色主题

6 层阶梯式表面，每层都带青绿色调，减少眼睛疲劳

✓

圆角设计

所有卡片用 1rem，按钮用 999px，数据友好且现代

✓

间距一致

6 级 spacing scale，布局节奏统一流畅

✓

色彩层级

青色主色 / 翠绿成功 / 橙黄警告 / 红色错误

交互细节

✓

卡片悬停

上浮 2px + 阴影增强 + 顶部渐变条淡入

✓

数据表格

行悬停高亮，标题背景突出，数据易读

✓

表单字段

聚焦时边框变色 + 青光环，输入反馈清晰

✓

状态标记

圆点状态 + 色彩编码，一眼看出运行状况

🎯 实现路径

  1. 第一步：Design Token 定义
    在 styles.css 中定义全部 token（颜色、间距、圆角、阴影等）
  2. 第二步：核心组件库
    更新按钮、卡片、表格、表单等基础组件的样式
  3. 第三步：模块适配
    依次适配工作台、交易中心、项目详情、资产账本模块
  4. 第四步：交互增强
    添加悬停、聚焦、加载等状态样式和动画
  5. 第五步：响应式优化
    在 960px / 760px / 540px 断点处调整布局

这是完整的模块美化预览。所有设计遵循统一 Design Token 系统，保证视觉一致性和可维护性。
