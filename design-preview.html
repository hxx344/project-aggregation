实现方式

采用 Design Tokens 方法，所有设计决策通过 CSS 自定义属性声明，组件只引用 token 而不硬编码值。 

/* 声明 tokens */
:root {
  --surface-2: #0F151C;
  --accent: #38BDF8;
  --space-lg: 1.5rem;
  --radius-lg: 1rem;
}

/* 组件消费 tokens */
.card {
  background: var(--surface-2);
  padding: var(--space-lg);
  border-radius: var(--radius-lg);
}

这种方法让整个系统保持一致的视觉节奏，修改 token 值即可全局更新，避免重复硬编码。

这是重构后的视觉效果预览。实际实现时会保留现有功能逻辑，只替换样式层。
