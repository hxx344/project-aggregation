## 🔧 技术变化

### CSS 架构

**重构前：**
```css
/* 硬编码，难以维护 */
.button {
  background: #087f83;
  border-radius: 7px;
  padding: 9px 14px;
}

.card {
  background: #fff;
  border: 1px solid #e0e7ef;
}
```

**重构后：**
```css
/* Token 化，易于维护 */
.button {
  background: var(--accent);
  border-radius: var(--radius-pill);
  padding: var(--space-sm) var(--space-md);
  transition: all .2s ease;
}

.card {
  background: var(--surface-2);
  border: 1px solid var(--surface-4);
  box-shadow: var(--shadow-sm);
}

.card:hover {
  transform: translateY(-2px);
  box-shadow: var(--shadow-md);
}
```

### 代码量

| 文件 | 重构前 | 重构后 | 变化 |
|------|--------|--------|------|
| `styles.css` | ~29KB | ~31KB | +6.9% |
| `trading-center.css` | ~8.3KB | ~9.1KB | +9.6% |
| **总计** | ~37KB | ~40KB | +8.1% |

**结论**：增加了更多交互细节和 token 定义，但文件大小增长控制良好。

## 🎓 开发体验对比

### 代码可维护性

**重构前：**
```css
/* 需要全局搜索替换 */
.button { background: #087f83; }
.link { color: #087f83; }
.icon { fill: #087f83; }
/* 修改主色调需要改 20+ 处 */
```

**重构后：**
```css
/* 修改一处，全局更新 */
:root { --accent: #38BDF8; }

.button { background: var(--accent); }
.link { color: var(--accent); }
.icon { fill: var(--accent); }
/* 修改主色调只需改 1 处 */
```

### 调试效率

**重构前：**
- 检查元素找具体颜色值
- 逐个修改测试效果

**重构后：**
- 检查元素看到 token 名称
- 在 `:root` 修改立即看到全局效果
- DevTools 实时预览所有引用

### 团队协作

**重构前：**
- 不同人可能用不同的灰色
- 间距和圆角不统一

**重构后：**
- 所有人使用相同的 token
- 设计系统文档化
- 新组件自然继承统一风格
