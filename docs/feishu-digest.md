# 飞书汇总

从侧栏 **系统 → 飞书汇总** 打开。工作台服务器按计划把各模块的主要信息发到一个飞书群，不需要打开页面；模块只走各来源已有的读取路径和缓存，不下单、不改设置。

## 配置

| 配置 | 说明 |
| --- | --- |
| 飞书机器人 | 群里「自定义机器人」的 Webhook 与可选签名密钥。用 `credentials.key` 加密保存，不在页面、接口或日志回显。独立于 Monitor 告警渠道 |
| 发送时间 | 每天固定时间（最多 24 个）或固定间隔（5–720 分钟，从本地零点起算），加星期与时区；夏令时回拨日重复的时刻只发第一次，前拨日不存在的时刻当天跳过 |
| 消息内容 | 标题、是否只在有问题时发送、是否列出问题明细、是否隐藏未启用的模块，以及每个模块和指标的开关 |

机器人开启「关键词」时请把关键词写进标题，否则飞书会拒收。

## 消息内容

| 来源 | 读取方式 |
| --- | --- |
| 各模块 | 总览的摘要指标与诊断 |
| 交易所持仓 | Asset 只读仓位 |
| 原油四腿资金费套利 | 交易中心 7 天状态 |
| 原生执行 | 执行状态：连接、持仓与任务 |
| Aero LP、Entropy / Lighter | 各自运行状态 |

- 单个来源读取失败或超时（20 秒）只影响自己的段落。
- 缺失值显示 `—`，不当作 0；来源不完整时在标题或合计旁标注；不同币种不相加。
- 「需要关注」只包含 `warn` / `alert`，非人工处理的故障持续 2 分钟后才计入，口径与总览一致。
- 未配置的来源（例如没有 Asset 项目）显示为未接入，不算故障。
- 问题明细中的 URL 替换为「地址已隐藏」，避免上游错误原文把请求地址带进群聊。
- 页面预览 15 秒内复用同一次读取，读取失败不缓存；实际发送总是重新读取。
- 飞书单条上限 20 KB。卡片控制在 19 KB 内，超出时从尾部省略模块并在页脚注明数量。

## 发送语义

| 情况 | 行为 |
| --- | --- |
| 正常 | 每个计划时间点至多发送一次：先记录时间点再发送，崩溃或响应丢失不会重复发 |
| 停用、改计划或清除机器人 | 取消等待中的重试；清除时还会中止进行中的发送，已发出的请求记为结果未知 |
| 服务重启 | 错过的时间点在 15 分钟内补发，超过则跳过 |
| 开启或修改计划 | 不补发保存之前已到点的消息 |
| 飞书明确拒绝（限流、签名、关键词等） | 间隔 60 秒，一个时间点最多尝试 3 次 |
| 结果不确定（超时、连接失败、5xx、响应无法识别） | 不重试，记为「结果未知」，避免重复消息 |
| 「只在有问题时发送」且没有问题 | 记为跳过；手动「立即发送」不受此限制 |

发送记录保留最近 20 条，连续的跳过合并为一条。

## 数据与回滚

数据在 `<数据目录>/feishu-digest/`：`config.json`（配置）、`channel.json`（加密的机器人地址）、`state.json`（已发送时间点与发送记录）。冷备份按数据根递归覆盖，三者都归入 secrets 域。

配置文件损坏时停用定时发送并在页面提示，保存后恢复；机器人文件无法解密时提示重新填写。

回滚：还原版本后功能消失，目录不再被读取，可保留或删除，不影响其他模块。
