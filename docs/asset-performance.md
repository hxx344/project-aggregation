# Asset 月度表现与年化口径

在工作台的 **Asset Ledger → 资产总览 → 资产变化** 查看收益指标。月表默认折叠，支持键盘展开；窄屏可在表格内部横向滚动。

- 调整后资产沿用 `assetTrend()`：实际持有资产 + 累计出金，只计已登记出金，入金未剔除。原表内出金不重复累加。
- 月度按北京时间自然月分组，使用该月首个与最后一个已有日快照，收益金额为两者之差，收益率为差额 / 起始调整后资产。不插值、不以其他月份快照补足月初或月末；表中展示实际快照区间，当前月标记“进行中”。
- 月收益年化只使用当前北京时间的上一个自然月，需至少两个不同日期且首末间隔至少 25 天。当前月不参与，缺失上月时不回退更早月份。25 天是最低观测跨度，不代表逐日数据齐全。
- 总体年化使用全部有效历史首末快照；有效日快照读取不再截断到最近 730 条。归档仍仅保留最近 730 条用于历史展示，且不参与趋势或收益指标。未来记录也不参与。
- 天数是首末日期的实际间隔，同一天为 0 天。单利年化 = 区间收益率 / 年份比例；年份比例按每个公历年的相隔天数 / 该年实际天数累加。平年使用 365，闰年使用 366，不计复利。例如 2024-01-01 至 2024-01-31 相隔 30 天，收益 1% 时年化为 `1% / (30 / 366) = 12.20%`。
- 只有一个日期的月份，收益金额与收益率均显示“—”；起始资产不大于零时收益率和年化显示“—”，不会伪装成 0%。旧值或缺失行情的快照保留并明确提示。

## 每日波动与来源

**资产变化** 面板下的“每日波动”默认折叠，展开时才读取 `/api/daily-changes`，账本数据变化后重新读取。

- 范围为北京时间今天往前 90 天（含今天）。每一行对比上一份已有快照，窗口内第一天以窗口前最近一份快照为基准；缺失日期不插值，间隔超过 1 天时标明天数。日期选择与曲线一致：同日优先日快照，其次最后一份原表记录，未来、归档记录不参与。
- 变化金额为两日“剔除出金影响”之差。来源按资产行（同一行编号）计算估值差，按变化绝对值排序，默认显示前 3 项；新增或移除的行以缺失一侧为空计入，小于 0.005 USD 的浮点差不列为来源。
- “出金（加回）”为累计出金变化（原表出金行 + 已登记出金），与提款对应的资产行减少相抵；“原表合计差异”为原表总额与行估值之和的差额变化，日快照通常为 0。各来源合计 + 出金 + 原表合计差异 = 当日变化。
- 日涨跌比例 = 当日变化 / 前一份快照的调整后资产，前值不大于 0 时显示“—”。入金未剔除，资产变化不等于投资收益；任一侧含旧值或缺失行情时标记“含旧值”。

实现与检查入口：`modules/asset/lib/daily-changes.ts`、`modules/asset/tests/daily-changes.test.ts`、`modules/asset/lib/performance-metrics.ts`、`modules/asset/tests/performance-metrics.test.ts`、`modules/asset/tests/snapshot-history.test.ts`。沿用项目的 Node 测试工具，不引入新依赖。

参考规格 `asset-monthly-performance-spec.md` 的示例代码存在固定 365、含首尾天数、完整月选择和零值格式的不一致；以上口径是实际实现与验收依据。
