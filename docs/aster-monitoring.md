# ASTER 币种监控中心

从工作台进入 Aster 5x，打开“币种监控中心”。原“USD1 上新”和“监控与告警”已合并，监控选择、公开额度和通知配置都在同一列表中。

## 配置方式

飞书总开关控制全部通知；每个币种的“配置通知”决定该币种发送哪些事件。选择通知后点击“应用”，保存失败时保留当前选择。清空通知不会暂停交易，也不会删除历史记录。

五种币种通知为新币上线、最大杠杆公开额度大于零、策略额度达标、普通开仓成交汇总和仓位不平衡。策略额度仅适用于现有策略品种；公开额度不是账户实际可开额度。服务器关闭策略额度通知时，页面会显示对应说明。

“独立币种监控”及单币监控开关控制后台公开数据采样。新币与额度通知依赖监控；成交和仓位通知保持原有业务条件。已有交易或订单核对仍可能需要采样，列表会列出相应原因。

“自动发现新币”控制目录扫描；“自动监控新发现币种”和新币默认通知只影响之后发现的币种，不批量覆盖已有选择。默认不会自动订阅所有新币的最大杠杆额度提醒。关闭再开启通知不会补发关闭期间的历史消息。

定时运行摘要和副服务器 WS 故障通知单独配置，受飞书总开关控制，不受单币类型选择影响。摘要间隔为 1–1440 分钟；保存新间隔后从保存时刻等待完整周期，保存相同间隔不改变安排。底部显示事件、定时两条通知通道及各自待发数量；通道未配置或发送失败会独立显示。

## 数据状态

| 状态 | 含义 |
| --- | --- |
| 监控中 | 监控已启用，目录及详情所需来源时间均有效 |
| 数据过期 | 等待首次样本、来源过期、时间无效或页面连接中断 |
| 已暂停 | 独立监控或本币采样关闭，或处于模拟环境 |
| 非交易中 | 交易所明确返回非交易状态 |
| 采样失败 | 最近目录或详情采样明确失败 |

新鲜度同时检查额度、杠杆档位和目录时间。关闭自动发现后，现有币种详情不再依赖目录持续刷新。页面时钟继续推进时，旧数据也会过期；暂停、失败或过期时保留上次数值并标记历史采样，不将未知额度显示为零。状态仅用于监控展示，不改变交易执行所需的有效期检查。

## 配置升级与旧客户端

服务启动时在数据库事务中将配置迁移到 `schema_version: 2`。每个币种保存 `monitor_enabled` 和 `notification_types`，全局保存 `auto_discover` 与 `default_notification_types`。原摘要、WS 通知、采样总开关及间隔继续保留。

迁移读取旧的币种选择和独立额度订阅记录，同时保留旧全局静音意图。只有原通知类型、币种告警及额度订阅同时启用，才迁移出该币种的最大杠杆额度通知。迁移保留已发送、待发送及摘要计时状态，重启不会重复迁移或重新推送历史。

现有接口路径继续使用：

- `GET/PATCH /api/monitoring`：读取或修改全局设置。
- `PATCH /api/monitoring/symbols/{symbol}`：修改 `monitor_enabled` 或 `notification_types`。
- `PATCH /api/listings/{symbol}/capacity-alert`：兼容旧额度提醒客户端。

旧 `monitor`、`alerts`、`max_capacity_alert`、`discovery_enabled` 及全局事件开关写入会转换成新配置操作；新版单币通知不再额外受这些旧事件开关约束。旧全局类型写入是兼容的批量操作，新版“新币默认通知”仅影响以后发现的币种。冲突的新旧字段、未知类型及无效币种会被拒绝。

旧接口至少保留至本功能首次正式发布后 30 天，当前版本没有自动失效或删除旧接口的计时器。发布继续使用工作台现有 `deploy-<commit>` 流程，不另设独立 ASTER 版本。

## 回退与验证

升级前应沿用现有数据库备份方式。已有旧配置会备份到 `monitoring_settings_v1_backup`，但它不是完整数据库备份：升级后新增的通知选择、消息和业务记录无法由旧配置快照完整表示。旧程序也不能表达任意的单币通知组合，不能直接将 v2 数据库当作无损兼容的旧格式运行。需要回退时停服，恢复经核实的升级前数据库备份并配套原版本；不要手工覆盖正在运行的数据库或删除业务记录。

回归入口：`modules/aster/tests/test_monitoring_status.py`、监控配置与通知相关 Python 测试、`modules/aster/dashboard/tests/monitoring-status.test.mjs`，以及从工作台登录、启动和 iframe 进入的 `tests/aster-monitor-center.browser.mjs`。浏览器使用隔离数据，不发送真实交易或飞书消息。

批量编辑、预设模板、配置历史、百分比灰度和性能指标统计保留为后续工作，本次未新增这些能力。
