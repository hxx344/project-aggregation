# 更新进度条 - 用户指南

## 新功能：实时更新进度显示 ✨

从 `3be993f` 版本开始，更新过程会显示实时下载进度，让您清楚了解安装进度。

## 使用方式

### 自动更新（推荐）

1. 打开工作台，点击右上角的更新图标
2. 如果有新版本，会显示：
   ```
   当前版本：ad7652d
   最新版本：3be993f
   ```
3. 点击"立即更新"按钮
4. **新功能**：您会看到实时进度显示：

```
┌──────────────────────────────────────┐
│ 正在下载更新包...        2.4 MB/s   │
│ [████████████████░░░░]  65%          │
│                       剩余约 30秒     │
└──────────────────────────────────────┘
```

### 进度阶段说明

更新分为 5 个阶段，每个阶段都有清晰的提示：

| 阶段 | 提示文字 | 说明 | 大约耗时 |
|------|----------|------|----------|
| 1️⃣ | 正在检查发布包... | 验证远程发布包是否可用 | 1-2秒 |
| 2️⃣ | 正在下载更新包... | 下载发布包到本地 | **主要耗时** |
| 3️⃣ | 正在校验完整性... | 验证下载的文件是否完整 | 5-10秒 |
| 4️⃣ | 正在解包... | 解压发布包到临时目录 | 5-10秒 |
| 5️⃣ | 正在切换服务... | 停止旧服务，启动新版本 | 2-3秒 |

### 进度信息说明

**进度条**：
- 显示当前整体进度（0-100%）
- 平滑过渡，不会跳动

**下载速度**：
- 显示实时下载速度
- 单位自适应：B/s、KB/s、MB/s

**剩余时间**：
- 根据当前速度预估
- 显示"剩余约 X秒/分钟"

## 常见问题

### Q: 为什么需要这么长时间下载？

A: 发布包大约 **104MB**，实际下载时间取决于：
- 网络带宽（建议 10Mbps 以上）
- 服务器连接速度
- 当前网络拥堵情况

示例：
- 10Mbps 网络：约 1-2 分钟
- 100Mbps 网络：约 10-20 秒

### Q: 进度条卡住不动怎么办？

A: 如果进度超过 5 分钟没有变化：
1. 系统会自动检测到超时
2. 显示错误提示
3. 您可以点击"重试"按钮

### Q: 更新失败会怎样？

A: 系统有完善的错误处理：
- **下载失败**：会显示具体的错误原因
- **校验失败**：会提示文件损坏，需要重新下载
- **切换失败**：会自动回滚到旧版本

所有错误都不会影响现有系统运行。

### Q: 可以取消正在进行的更新吗？

A: 
- **下载阶段**：可以关闭浏览器，下次继续
- **切换阶段**：不建议中断，可能导致服务不可用
- 如果意外中断，系统会自动回滚

### Q: 旧版本工作台能看到进度吗？

A: 不能。旧版本会按原有方式更新（无进度显示）。更新到新版本后，以后的更新就能看到进度了。
