# ChatGPT 项目指引

本项目的规则入口是 [AGENTS.md](../AGENTS.md)。开发和复盘均从该文件开始，按其指引读取相关经验与规范。

## 开始开发

在已连接仓库或能够读取项目文件的会话中，请助手先读取项目根目录的 `AGENTS.md`，再按其中的指引读取相关引用文件。

在无法访问仓库的普通会话中，需要提供 `AGENTS.md` 及本次任务所需引用文件的内容，例如粘贴内容或上传文件。仅提供路径或文件名不等于提供了文件内容；助手只有实际读到内容后，才能说明已读取。无法读取的文件应明确说明，不推断其规则。

可使用以下开场提示：

> 请协助开发 project_aggregation。先读取项目根目录的 AGENTS.md，并遵循其中的文件引用和开发流程。无法读取的文件请明确指出；我会提供所需内容。本次任务是：……

## 进行复盘

读取 [daily-review-prompt.md](../daily-review-prompt.md)，按其中的流程从 [docs/review-state.json](./review-state.json) 记录的提交 SHA 到本次固定目标 SHA 确定审查范围，再更新经验、规范和复盘状态。普通会话需要提供相应文件内容及该范围内的提交证据，才能完成可核实的复盘。

这些文档本身不会自动定时执行。需要复盘时，应显式发起任务；是否设置定时任务由用户另行决定。
