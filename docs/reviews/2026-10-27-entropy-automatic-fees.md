# Entropy 自动费率与两档返佣

风险等级 R3。用户明确要求自动取得费用、以额外渠道确认的全部 Entropy 手续费为基数，分别按 110% 和 120% 计算返佣，不要求用户手填费用或返佣参数。自动读取仅使用公共费表和市场参数，不读取用户实际账户、不签名或下单。

实现采用全局官方费表、HIP-3 市场倍率与 growth mode 组合的默认档费率，Lighter 使用公开 Standard 档；报告明确默认档与账户实付费率的区别，研究路径不附加 builder 费用。费用按标的保存来源、版本、读取时间与有效期；费用请求失败不能影响行情采集，过期费用不能被新报告心跳续期。

每条原始研究、延迟探针和纸面开仓锁定自己的费用快照；费用语义改变时不把旧版本统计混入新版本候选，也不重算历史结果或抹去在途纸面敞口。原配置 schema 1 保持可读，旧手填字段兼容保留，但新自动运行不再用其覆盖公共自动费用。两档返佣为未到账的渠道情景，不改变原有返佣前准入和合约核验门槛。

影响范围为四文件研究工具中的费用读取与计算、现有报告投影/结论、原生页面及相应定向测试和使用说明。回滚到上一正式版本，保留配置与原始研究记录，新增报告字段可忽略；不新增部署服务，不部署用户服务器，严禁 WSL。实施前已完成隔离只读 Ultra 规划，交付前按固定差异完成独立 R3 审查。

## 实际验证与审查

- 匿名公共接口实测：Entropy 两市场得到默认 `0.9 bps`，Lighter Standard 两市场 `0 bps`；Entropy 基准来自 `feeSchedule.cross`，未使用零地址的账户费率或用户数据。固定费率源解析、单位、分段倍率、未知字段、请求失败及限流共 20 项通过。
- 自动费用 5 项、CLI 5 项、工作台/API 9 项、策略结论 57 项、原有研究核心 22 项均通过，共 118 项；其中未变输入的有效检查复用，备份缺失当前配置分支追加后仅重跑该定向用例 1/1。覆盖未知费用不补零、逐标的费用差异、20 分钟有效期不被心跳延长、旧手填值不覆盖自动模式、语义版本隔离、研究/在途纸面锁定、完整四次费用和返佣、旧报告不重算。
- 前端 `pnpm run build`（包含类型检查）通过。生产浏览器完整夹具通过，7 次配置/启停写入、45 次读取；覆盖两个旧费用字段均 null 时自动得出成本、110%/120%两档、默认费档来源、不同标的费率、同版本刷新保留历史、费用在两次 GET 之间精确到期和版本错配时即时撤回结论，以及原有时效/启停/身份/300ms/登录路径。桌面与手机截图已目检，无页面异常。
- 独立只读 R3 审查发现并修复一项 P1：客户端费用过期标签已变化但仍保留候选。另修复 P2：当前配置缺失时不能覆盖唯一升级前备份。审查者独立复核公式、React 内存边界和备份删除/恢复分支，当前 P0/P1/P2 均无未处理项。
- 费用缺失/将过期每分钟恢复尝试，遵守共享持久冷却；15 分钟正常刷新不重连相同市场订阅。未重复未改动模块的本地全套回归，正式发布仍等待对应 Linux CI。
- 按通用、计算、缓存调度、失败路径、资金边界和前端类别完成自审；未新增鉴权、凭据、真实执行或部署入口，相关未变路径不扩大全仓扫描。L080 与经验路由一致性 2/2 通过。

回滚补充：单向 schema 1 可读不等于旧版接受新启用 paper/null 费率组合。初始化保留一次 `config.before-auto-fees.json` 且不覆盖；回退前关闭 paper，或停服恢复升级前备份，再使用旧正式版本。旧原始记录、未决纸面状态和暂停保护全部保留。没有进行用户服务器部署或真实订单验收。
