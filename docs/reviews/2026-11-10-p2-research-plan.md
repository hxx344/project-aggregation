# P2 研究证据与规模基线实施边界

范围：#324 研究日志片段导出、#327 单次期权回测证据、#329 只读数据预检、#313 清理规模/中断基线、#317 持仓资金费轮转基线。

风险：新增只读 API/CLI 的公共输出契约按 R3 审查。研究计算证据按 R2；独立规模夹具按 R1。导出只读现有文件，不采集、不交易、不启动模拟；预检复用真实 spec、market、小时标签和合约选择规则，禁止下载和写缓存。回测计算保持原有价格、费用、结算与 carry 语义，新增证据不改变金融结果。

影响面：`tools/entropy-lighter-lab`、`server/research/entropy-lighter*` 与 Entropy 页面；`tools/options-backtest`；独立清理及资金费调度测试。公共服务路由由主任务接线。日志读取限定会话、标的、时间、扫描字节/条数/文件数/时长、输出字节/条数，跳过非普通文件，坏行和缺段不声称完整。

回滚：回退对应源码变更即可关闭新增入口；无需数据迁移，保留原日志、配置与已输出结果。新回测结果写入独立目录，不覆盖已有冻结证据。清理与资金费基线只使用隔离目录和受控 reader，不修改生产预算或保留策略。

最小验证：期权引擎既有测试及新预检/证据真实 CLI 夹具；日志导出边界和服务方法测试、前端类型检查与对应交互；Windows 原生清理/资金费规模测试。Linux 安装器夹具通过现有 CI 执行，不使用 WSL。独立审查与公共接线验收由主任务完成。
