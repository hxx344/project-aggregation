# 账户写入保护只读诊断（#331）

风险等级：R3。新增现有受鉴权 GET 的诊断契约，读取共享账户保护注册库，涉及交易保护证据的展示与脱敏。实现前确定范围：Node 统一投影 Node/Python 记录；不改变租约、fence、owner、操作状态、恢复准入或数据库结构；不提供解锁、认领或结算操作。

影响面：`server/execution/account-writer.mjs`、账户诊断 GET 接线、`src/AccountWriterDiagnostics.tsx` 及诊断页可见性接线、定向回归。未知模块在线状态、读取失败及截断不能表示可写或无未决；每次断线/隐藏后重新读取成功前旧快照仅作为历史证据。

回滚：回退本批诊断投影与页面接线即可；无 schema 迁移、无新增持久数据，无需改动或删除现有注册库。既有 snapshot 字段保留；详细投影仅显式请求时计算，既有交易准入读取不增加该查询。

最小验证集：原账户保护 Node 回归、新增诊断（多模块租约冲突、过期/关闭/缺失 owner、sending/unknown、隔离、坏库/缺库、脱敏、截断、重复读取无副作用、Python 产生的记录）、前端类型检查与实际诊断页可见性/离线恢复浏览器验收。独立安全审查由主任务组织；发布/提交由主任务统一完成。

## 作者自审与验证

实现保留默认 `snapshot()` 的既有契约与交易准入开销，仅 `includeDiagnostics: true` 计算详细投影。账户/模块候选、Owner、未决计数、模块汇总从同一 SELECT 收集；如果恢复状态在前置校验与收集期间变化，本次返回未知并等待下一次 GET。缺失模块证据的数量使用 null。诊断专用注册库检查只读文件，不调用可能恢复临时硬链接或退役实例的准入检查；任何错误均只返回固定原因码。

Node 读取共享 SQLite 的统一投影覆盖 Python 写入者，无需扩充 Python 的交易协议。脱敏引用使用注册库身份作域隔离；不投影账户键、原 UID、connectionId、operationId、私有 ticket、运行路径或上游错误正文。注册库最多展示 200 条账户/模块记录，公开完整性及总行数；零未决仅描述已读到的该账户注册库记录，页面不据此声称可写。全局恢复状态原结构没有时间，返回 null 并明确显示未记录；账户隔离显示实际 created_at。

页面只在 active、document 可见且在线时 GET；单请求超时 10 秒，完成后等待 15 秒再读，无重叠重试链。离线、隐藏与失活中止在途读取，重新激活或上线先进入等待新证据状态。错误仍保留旧证据并标明当前状态未知；401 交给会话退出。界面仅新增刷新读取，不含交易或保护状态写入口。原用户主动启动的请求监控功能继续保持其跨页面记录语义。
