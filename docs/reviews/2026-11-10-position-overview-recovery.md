# 持仓概览的短暂读取失败与恢复

风险等级：R2。交付基线 `688aa97baaf5ee2f2caa254cfd8f164755453764`。仅修改工作台浏览器的缓存 GET、网络失效和诊断展示；无交易所、下单、凭据、数据库或安装器变更。

## 原因与范围

用户在价差下单页持续停留时，原油、海力士偶尔同时显示过期，随后恢复。前端单次 `/api/trading` 失败立即令缓存失效，但错误和重试入口藏在其他页签；`fetchedAt` 与交易所仓位变更时间已分开，不是“持仓未变化”造成。以 `feb56f0` 的原实现生成生产构建，注入第一次 503 后，回归失败于 `oil: source is live`；这三个旧前端源文件在交付基线内容相同。未读取用户服务器日志，不能认定所有现场过期都来自同一错误。

缓存 GET 最多两次尝试、间隔 1 秒，每次 12 秒，总预算最多 25 秒，沿用同一请求取消、代次与在途合并。只重试明确传输故障及 408/502/503/504；401/403/429、无效成功响应与存在任意 `Retry-After` 时不即时重试。公共 API 仅透传错误的等待元数据，不给其他请求添加重试。

短暂失败在有界重试内不提前撤销仍在来源有效期内的缓存，75 秒期限照常推进。持续失败保留行、撤回合计，并在价差下单和原数据页显示诊断与只读重试。断网由持有缓存的 App 统一标记失效；即使断网发生在其他页面，联网后也须新响应才恢复有效性。
