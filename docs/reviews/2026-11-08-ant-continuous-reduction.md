# ANT 自动减仓完成后持续监测

风险等级：R3。用户明确要求强平距离自动减仓完成一轮后继续运行。

## 变更前范围与回滚

- 仅修改 ANT 自动减仓调度、执行器的该入口、对应页面说明与回归。成功且规则仍启用时回到监测，下一次检查用当前剩余持仓计算新一轮；风险恢复时等待。前轮任务与成交结果仍可查看。
- 新一轮前先按前轮持久任务及真实成交核对两腿剩余持仓，防止尚未反映成交的旧快照被用于重复减仓。核对在首次成功读取后结束，不永久固定以后监测的仓位。旧快照沿用三次失败预算和至少 30 秒间隔；异常、未知结果、维护、账户变化与手动停用仍遵守原保护。
- 保留交易所适配器、公共任务停止与人工恢复政策、下单方式、每轮比例和拆批规则；ANT 人工继续时额外保留每腿最后确认的持仓依据。不自动重新启用旧版已停用的规则。服务器部署由用户执行。
- 回滚：先用页面“停用新触发”关闭续轮，必要时通过既有执行入口停止当前任务；回退本次提交并按既有发布流程发布。保留任务、委托、成交及账户保护数据，不删除或伪造终态。新增 JSON 状态字段不改变数据库结构，旧版忽略历史/核对字段。

## 验证计划

运行 ANT 自动减仓服务与 HTTP 集成测试，覆盖剩余量续轮、阈值恢复再触发、并发与重启、防重复、旧快照有界等待、手动停用、失败和数量不足；执行器共享文件另跑直接相关回归。运行工作台类型检查/构建与该页面生产浏览器夹具，验证监测、上一轮回执、下一轮及停用。固定差异进行独立只读审查和交易边界安全审查，提交前运行 staged review gate。只用 Windows 原生和既有 Linux CI，不使用 WSL。
