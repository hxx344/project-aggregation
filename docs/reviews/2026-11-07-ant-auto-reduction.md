# ANT 强平距离自动分批减仓

后续行为变更：2026-11-08 按用户要求改为成功后持续监测与按剩余持仓续轮，见 [续轮记录](2026-11-08-ant-continuous-reduction.md)。下文保留初版交付时的审查事实。

风险等级：R3。用户要求任意一腿距离强平达到阈值时双边市价减仓，并明确要求减仓比例与批次数可配置。

## 影响面与执行契约

- 新增独立的 ANT 双腿规则、服务端轮询、持久状态与配置界面；阈值、总减仓比例、批次数、间隔和最长执行时间可配置，默认关闭。
- 使用所选实盘账户的风险快照，绑定连接版本与身份；不采用只读仓位面板作为下单依据。Lighter 只操作实盘连接指定的 accountIndex。
- 距离按标记价格计算，多头 `(标记价−强平价)/标记价 × 100%`，空头 `(强平价−标记价)/标记价 × 100%`；达到或越过强平价按零距离处理。任一腿距离小于等于阈值触发，两腿风险数据均须有效、新鲜。
- 每腿按触发时原生持仓数量乘总减仓比例、向下对齐步长，拆成多批市价平仓；总比例不是每批比例。每批双边完成且委托终结后才进行下一批，完成后停用，重新启用须显式确认。
- 规则触发记录与执行任务、合约锁在同一 SQLite 事务保存。首批发送前复核风险、连接与持仓；部分成交、结果未知或外部仓位变化时暂停并保留原订单核对，不自动另起补仓任务。
- 复用原有市价执行、只减仓语义、账户共享写保护与维护门。Hyperliquid / Lighter 的市价沿用现有对手价 ±1% IOC。
- 四个实盘适配器增加仅用于 ANT 的可选风险字段；不新增交易所请求，不改变其它市场的仓位数据形状。

## 回滚

先停用规则，完成或停止其关联执行任务，并核对所有原委托终态后再回退到上一正式版。旧版本不理解风险任务元数据，不得带着待发送或未决风险任务直接回滚。新增 SQLite 表可以保留，不删除订单、成交、连接或共享写保护记录；再次升级保留停用与核对状态。正式发布不执行服务器部署。

## 审查发现与修复

独立审查者：隔离上下文的 `ant_reduce_review`，调用指定 `gpt-6-astra` / `ultra`，只读审查固定差异并应用 Codex Security（扫描 `b865f84b-c46c-4e2a-8709-acbca1d7591e` 已完成并读回）。初始固定源码范围 `b524404..eb2121c`；新增测试固定于 `c3fb9e8`；恢复修复增量固定于 `a9fc963`，最终事务边界增量为 `b96fc49`。临时快照只用于审查，未推送为分支。

- P1：所有 409 被当作永久拒绝，使一轮旧盘口导致规则永久停用。独立假账户探针实测复现；现排除 `StaleMarketError`，按三次持久读取预算恢复。
- P1：风险读取期间租约被接管，旧实例仍可写失败状态并停用新实例的规则。独立真实执行器探针实测复现；失败写回、无触发清失败、任务终态更新均在短写事务内重新核验租约。独立探针确认这三条真实路径各一次 UPDATE，且 UPDATE 与最近一次有效归属检查都处于同一事务；复核源码 blob 与最终快照一致。
- P2：本地 180 秒上限可能截短执行器返回的限流截止时间。现保留原期限，新增跨重启与期限内零读取用例；目前 RH 适配器未产生大于 180 秒的期限，不描述为已发生的线上故障。
- 作者自审：前端原先按响应数组顺序认领多空腿，排序后可能反转。已按 `side` 查找并补生产浏览器回归，经验登记至 L020；恢复错误与失租写回分别登记 L103、L083。
