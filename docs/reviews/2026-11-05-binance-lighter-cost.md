风险等级：R3。基线为 `4bb440e74daf9bba20b9b5fedea33604578d42ea`。范围是新研究服务、行情/模拟执行适配器、工作台 API 与页面、对应测试和说明，不涉及真实交易或服务器部署。初次审查的暂存树为 `d33d3624ef55f18ee0671a225b5036a2fb87fb8c`；后续只对修复增量及其关联路径复核。

## 独立审查

独立审查者 `cost_lab_review` 使用隔离上下文，只收到仓库、固定差异及审查标准。第一轮覆盖 15 个文件，另核对打包、鉴权与内部转发消费者。发现 3 个 P1、1 个 P2，均在首次提交前修复，未发生线上交易。

| 发现 | 修复与独立证据 | 最终状态 |
| --- | --- | --- |
| P1：盘口恢复误清成交通道故障 | 按通道保存无效状态；live 通知不授权数据使用，逐笔（含 `nq=0`）通过源/接收时钟校验后才恢复。必要通道重连耗尽终止整个采集。第三轮实际 decoder → engine 探针覆盖未知、故障、曾健康后收到旧源、零量和正量、有效恢复后确实 Maker 成交及对冲，旧未决不复活 | 关闭 |
| P1：晚到的旧盘口用于延迟对冲 | 同时约束单调到达时间和来源时间下界。独立探针确认 Maker t1000 后收到 source t700 的盘口不成交，而到期点减 250ms 的边界仍能正常对冲 | 关闭 |
| P1：完整历史进入常规轮询 | 轻量状态、单情景详情和完整导出分离，并在成本路由协商 gzip。真实引擎 12 情景各 20 轮时，状态正文 8,546B、gzip 1,694B；单情景详情 gzip 12,818B；完整约 4.83MB 报告深比较一致。summary 的历史属性设为抛错 getter 仍成功，确认不先克隆全部历史 | 关闭 |
| P2：归档未决重复计数 | 未决情景数与 interrupted 标记分开。独立真实 engine/manager 探针确认一条未决归档仍为 1、原正文完整 | 关闭 |

第二轮关闭后三项，第一项还存在 live 通知先于时效校验的残留；第三轮只复核该增量并关闭。最终限定范围无未处理 P0/P1/P2，没有重复全仓审查。

Codex Security 对首次固定差异的扫描 `05901070-d27c-4cf9-8e7b-68ac12ff397c` 已完成，覆盖 10 个产品源码文件及额外文档/测试，记录一项低风险资源缺陷 `csf_c10a70ddfdc3d8424d02b8e7`：受控或畸形的固定上游消息可用超长序列触发同步 BigInt 运算。普通未认证 HTTP 用户不能直接注入该输入，未声称资金影响。

修复后由非作者 `cost_security_discovery` 独立增量复核：所有 wire、缓存和直接引擎/适配器入口在 BigInt 前限制 1–40 位；原 7,000,199B 输入从约 1,926ms 变为约 3.4ms 拒绝，20/40 位正常。另核对新增详情的会话绑定与 gzip 范围，未发现新增安全候选。原封存报告保留修复前事实，修复结论由此增量记录承接。扫描工具记录总量 13,772,066 tokens，其中缓存输入 13,490,432；该工具口径包含其关联会话，不作为模型性能对比。
