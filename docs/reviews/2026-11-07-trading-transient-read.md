# 套利执行：委托状态临时读取失败不再立即暂停

风险等级 R3：交易执行状态机（`server/trading-execution.mjs` 的 `runJob()`）。

## 背景

2026-11-07 03:17（北京时间）Anthropic 跨所两腿开仓任务 `991841cb-…`：第 1 批 Binance `ANTHROPICUSDT` 0.78 已全部成交，Hyperliquid `io:ANTH` 买单挂单未成交时，一次委托状态读取失败即暂停并撤销余单，留下无对冲的 Binance 空单。旧事件不记录失败腿与错误，具体错误码无法核实。

## 影响面

- 传输类读取失败（`timeout`、`transport`、`upstream`、未关闭时的 `aborted`、Binance -1003 / Bybit 10006 / OKX 50011 限流）跳过本轮，不改价、不撤单、不下新单；至少 3 次且满 20 秒后才暂停。窗口状态只在内存，重启即清空（重启本身会暂停任务）。
- 数据格式、身份数量不一致、提交结果未查到仍立即暂停；暂停原因写明交易所、合约与错误。
- 停止、到期、`attention`、`stopping` 在读取前处理，窗口不影响。无数据库结构与接口变化。

## 回滚

revert 本次提交即恢复为任一读取失败立即暂停；无数据迁移，可直接切回上一正式版。
