# Lighter RH 执行只读限流恢复

风险等级：R3。目标是让执行中的明确只读限流按可恢复时间等待，避免单次配额耗尽立即撤销未成交的对冲腿。

## 范围与回滚

- 仅修改工作台执行引擎 `server/trading-execution.mjs` 和对应 Lighter 回归；Lighter 本地 40 次/分钟限额、缓存有效期及交易所写入判定保持原契约。
- 账户验证/快照、盘口、原单状态和撤单后的核验统一经过只读边界。仅 Lighter RH 的明确限流、非不确定结果、有效恢复时间进入等待；写请求错误不获得只读重试资格。
- 首次失败起固定 180 秒，最多三次恢复尝试；等待 tick 不计尝试且不读取交易所，不截短合法恢复期限。运行锁、用户停止与任务截止先检查；恢复重新读取所需证据。
- 同轮状态读取成功不清除后续账户/盘口失败预算；只有所需读取和校验完整成功才复位。已接受未可见建单的确定性“查无”响应仍遵循原签名观察窗口，不重发。
- 并行读取全部结束后选择错误；成功返回的数据也先完成适用的身份、账户、格式、规则、价格及订单终态校验，非限流错误优先，避免较快的限流响应遮住另一腿的真实失败。
- 无数据库迁移、配置、UI、部署或真实账户操作。回滚：撤销本次提交并按既有流程重新发布，保留已有订单、成交与恢复记录。
