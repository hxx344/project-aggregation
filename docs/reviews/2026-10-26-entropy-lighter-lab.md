# Entropy / Lighter 研究工具交付审查

风险等级 R3。范围为独立行情/纸面工具、专用安装器和验收、CI 发布依赖、使用说明及 L078 经验补充；不涉及已有工作台实盘执行。

## 独立只读审查

审查代理在隔离上下文读取标准、差异和关联路径。覆盖 core、CLI、feeds、配置、三份 Node 测试、安装器、Python 事务检查、真实 systemd 验收及 CI 接线。最终未处理 P0/P1 为 0。

审查确认并在本批修复：未决敞口的已知费用不得遗漏或显示零净额；崩溃重启即使尚未生成最新快照也须暂停纸面交易；原始未决报告多次重启不覆盖；两个恢复进程不得同时抢占独占目录；current 符号链接启动必须执行主模块；服务器限流截止时间立即持久化。

保留 P2 已登记为 [#63](https://github.com/hxx344/project-aggregation/issues/63)：启动仲裁区间被 SIGKILL 后，残留 `run.claim` 需停服核对后手动清理。使用文档明确记录，不声称所有启动中断均自动恢复。

## 自审证据与边界

- 数据语义：原生合约、倍率、精度、最小量与计价币保留；ANTH 结算等价性未核实。研究接收时间观测标明源时钟质量，纸面准入拒绝无效源时间。
- 失败恢复：丢序重订快照、断线失效、有限重试、跨重启限流、两腿独立延迟/失败/撤退及未知退出均有定向案例。写盘错误终止研究；原始数据与 session 可追溯。
- 权限/资金：仅允许公开行情端点，无凭据、签名或订单路径；非 root 专用服务。root 安装只用固定正式提交的白名单源码和受信任 Node，激活失败恢复旧 current 与服务状态。
- 实际验证：独立审查重跑 core+CLI 19/19、feeds 13/13；安装器跨平台 4/4 通过，10 项 Linux 事务在 Windows 跳过。作者另跑经验路由 2/2、三工具语法检查。Shell 语法用 Windows Git Bash 校验通过，未使用 WSL。
- 真实公开接口：作者最终 20 秒采集 161 条盘口，两个标的均形成带时间质量的基差样本；Entropy/Lighter 各两路公开 WS 均实测。Binance 受本机出口网络/限流限制，本机没有验证其真实领先效果。上述不能代替东京服务器 24 小时采集或实际订单延迟测量。
- 待 CI：新增 Ubuntu 原生事务、真实 systemd 首启/无变化/隔离/保留配置数据/升级失败回滚已接入 `release.needs`，正式发布须等待它们及已有正式发布必需检查通过。
- 不适用：工作台可见交互、前端类型/样式、既有订单鉴权与数据库迁移均未改；未为这些路径重复运行浏览器、全仓类型或安全扫描。
