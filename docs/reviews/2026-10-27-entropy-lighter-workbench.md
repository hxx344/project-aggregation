# Entropy / Lighter 内置工作台接入

风险等级 R3。将既有公共行情采集和纯 taker 模拟接入原生研究页，由工作台 runtime 托管固定 CLI 子进程。新增 API 沿用既有登录、Origin 与 CSRF 校验；研究参数不能指定命令、文件路径、外部地址或凭据。界面在监控区提供启动、停止、配置、报告和近期基差图；关闭页面不会停止后台采集，API 独立热更新不会重启采集进程。

影响范围为 `server/research`、runtime 数据面与 HTTP 路由、原生 React 页面、研究工具快照字段，以及正式包/源码部署的白名单与内容键。现有实盘执行和数据库结构不变，不新增对外端口、不增加独立 systemd 服务。

失败时保留历史报告和原始数据，显式显示断线、过期或进程失败；采集进程采用有界停止和崩溃重试。用户停止决定持久化，纸面未决敞口的已有暂停规则继续有效。独立版本的数据不自动迁移，已有独立服务由用户先停止，避免重复采集。

回滚沿用工作台已有正式版本回滚，保留 `DATA_DIR/entropy-lighter`；旧版本不读取新研究目录。实施前已完成隔离只读规划，最终固定差异需独立审查，鉴权/子进程/部署边界按适用安全审查流程核对，发布前补充真实验证证据。

## 实施与验证记录

原生页 lazy 加载，单个 Recharts SVG 展示所选 SNDK/ANTH 的中间价差和双向最佳 taker 价差，单位 bps；每标的最多 600 点、正常最少间隔 2 秒。失效插入 null，时间缺口留空；关键数值在图外可读，手机保留运行状态和主要观测。页面仅可见时每 5 秒轮询，恢复事件合并，断线保留旧图并标记过期；采集生命周期属于 runtime，不受页面轮询影响。报告绑定 `sessionConfig`，更改保存配置不改变旧会话的费率/延迟说明。

实际运行和有效复用：

- `pnpm run check` 与 `pnpm run build:bundle` 通过，研究页为独立 lazy chunk，无新增依赖或锁文件变更。初始依赖目录缺实际文件，pnpm 的乐观重复安装跳过了修复；关闭该本机优化并按冻结锁恢复后完成检查，未修改项目依赖配置。
- Lab/CLI/manager/API 最新 28 项通过；POSIX 双进程 13 项在 Windows 跳过，其中新增采集会话跨 API-only 重启的实际 socket 路径由 Linux CI 执行。后续修复无效持久控制文件的定向 1/1 通过。
- feeds 13 项和既有 `api-server` 14 项有效复用；源码未变，不重复运行。实际工作台 API 测试覆盖登录、Origin、CSRF、路径/字段白名单、真实 CLI 启停、配置只在停止后保存、崩溃重试、退出升级、过大报告和重启保留。
- Windows 原生发布布局 31 passed、2 个既有 symlink 案例跳过；release 11 passed；runtime-lock-parser 3 passed、6 个 Linux root 案例跳过。工具最后修改后额外重跑两个真实打包/source archive 的 CLI `check` 案例，2/2 通过。原生 Git Bash 的输入键检查、相关 shell 语法通过；未使用 WSL。
