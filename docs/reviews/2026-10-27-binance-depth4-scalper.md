# Binance 第四档领先剥头皮模拟

风险等级 R3。用户确认买4、卖4指 Binance 盘口第四档，要求在工作台研究模块尝试突破后在 Entropy 顺势 taker 开仓、反向回落平仓。沿用公开行情研究边界，不新增签名、账户或交易写接口。

## 实施前范围与回滚

新增独立方向研究状态机，复用已接入的 Binance top20 完整快照和 Entropy 深度；冻结 bid4/ask4，只在后续 bid1 上穿 ask4 或 ask1 下穿 bid4 触发，另一侧撤销，多仓 bid1 回落到原触发价下方、空仓 ask1 回升到原触发价上方退出。最长持有、冷却、名义金额、滑点、资金费准备和 Entropy 假设延迟沿用既有配置，无新必填字段，原四腿 paper 开关及跨所等价确认不作为本方向研究的启动条件。

各延迟情景独立，不合计交易量或收益。入场已假定发出后反向不能追溯取消；两次模拟成交均只用到达后新收到的 Entropy 盘口。费用仅依赖单独有效的 Entropy 默认费档，逐笔锁定快照；计入两次吃单费和单腿资金费准备，110%/120% 返佣按全部 Entropy 手续费单列未到账情景。未退出敞口净收益未知，失败和亏损样本保留。退出超时及前次会话未决状态阻断再次模拟，不静默清零。

前端沿用现有 React、服务器时间锚点和五秒报告读取，新增最多两个延迟情景的状态/触发价/收益表与有界逐笔明细，无新连接或图表库。当前状态、缺数据/停更/历史状态先于收益展示；手机沿用同样阅读顺序，细表仅局部滚动。Binance USDT 价只产生方向信号，不与 Entropy USD/USDC 价直接相减；ANTH 领先关系仍待验证。

影响面为独立引擎、Lab 接入、CLI 未决恢复、报告白名单/类型、研究页与相应定向检查。固定发布/安装清单同步新增独立引擎文件，避免运行时 import 缺文件；不改配置 schema、服务权限、来源校验或部署激活边界。回滚到前一正式版即可恢复原策略，保留配置和原研究日志；方向研究的未决报告及归档保留，不把旧版忽略字段解释为已经平仓。用户服务器由用户更新，不执行服务器部署，禁止 WSL。

## 验证计划

引擎覆盖双向第四档冻结、等号边界、点差扩大、重复帧、OCO、到达后新盘口、延迟途中反向、深度/超时/失效、两次费用、两档返佣、在途及重启未决。Lab/CLI/工作台定向集成覆盖默认研究模式、费用独立性及报告透传；前端类型与生产构建后，用工作台实际入口的浏览器夹具验证默认状态、持仓未知收益、亏损、两场景、过期/停止和标的切换。未改动的已通过检查按输入复用，提交前固定差异独立审查及门禁，发布等待对应 Linux CI。

- 方向引擎 13 项、Lab 方向集成 3 项、原研究核心 22 项、自动费率 5 项、结论投影 57 项、真实 CLI 7 项、工作台/API 9 项、行情解码与接入 20 项通过，共 136 项；最后行情组由独立审查运行，其余由主任务和引擎代理运行。最后仅报告中的非亏损率字段正名为 `nonLossRateBeforeRebate`，重新运行受影响引擎/集成 16 项及类型检查通过，前端不读取此字段。
- `pnpm run build` 包含类型检查通过；最终生产浏览器夹具 19 次读取、仅 1 次显式停止写入通过，console/pageerrors 为空。覆盖默认研究、冻结阈值、各延迟、亏损/返佣、持仓未知、上次未决会话保留费用/成交额/亏损、未清洁但空任务时收益未知，以及停更、离线、停止、偏钟、ANTH 与手机 390px。桌面/手机截图已目检。
- Windows 原生 Python 部署检查 67 项，49 通过、18 因 Linux/链接环境跳过；6 个受影响脚本原生 Git Bash `bash -n` 通过，`deploy/test-inputs.sh` 通过。发布助手首跑因测试 PATH 缺 Git 工具失败，补该测试进程 PATH 后 11 项通过，没有修改产品逻辑。固定源码提取与完整发布包均实际启动 CLI 导入新引擎；未将 Windows 跳过项视为 Linux 安装通过。

- L081 记录本次未发布实现的重启投影发现，经验路由 2 项通过。按通用、计算、状态/时效、失败、资金边界、前端和交付类别完成自审；不新增账户、凭据或交易写接口，配置 schema、权限与激活逻辑保持既有契约。最终 Linux/systemd、双槽整合和发布包仍按实际 CI 结果核实。
