# 技术演进迭代初稿

版本：v0.2，2026-11-07。源码基线：`3e0e5ee`（v0.1 为 2026-10-30 的 `37cb9e2`）。依据为[全面审查报告](comprehensive-audit-2026-10-30.md)、对应 Issues、合入 PR 的验证记录和[架构实现方案](architecture-implementation.md)。结构层面的演进（hub schema 版本、共享交易所传输层等）见[架构演进方案](architecture-evolution-draft-2026-11-03.md)，本文只跟踪业务正确性批次。

首轮 A–F 引用的 18 个 Issue 已全部关闭，两项产品决策已定。代码修复与离线回归已完成，但多数路径没有真实交易所或生产环境验收；正式安全深扫、生产容量与恢复证据仍未取得。下一轮重点从“修缺陷”转为“补证据”：安全深扫、生产基线、架构基线更新和少量登记 P2。现有模块化单体、进程隔离、SQLite 与统一发布继续作为基础；本轮测量仍未出现需要微服务、PostgreSQL 或换语言的证据。

首轮落地的约束，后续改动不得回退：

- 发送依据：最终发送前失效为明确未发送；请求已可能送达的保持 UNKNOWN，不因时效门自动清零。
- 异步写入：锁令牌防止旧任务释放新锁，账本/凭据版本校验防止旧结果覆盖新值，两者在同一短事务内完成；外部请求不进长事务。
- 活动完整性：活动/未知订单与外部委托完整返回，只有终态历史限量分页；归档不得删除未知订单、原操作身份或恢复依赖。
- 部署目标：激活只针对本轮正式提交，目标不符明确推迟；缓存命中仍复核健康端点与部署记录。
- 研究数据：单位显式声明，含混输入拒绝；缺报价或未结算保留未决，不生成假零值。

## 3 横向契约与实施约束

| 契约 | 最小内容 | 失败行为 |
| --- | --- | --- |
| 动作依据 | 账户身份/代次、快照源时间、行情源时间、规则版本、原意图 ID | 最终发送前失效为明确未发送；已可能发送保持 UNKNOWN |
| 异步提交 | owner/token/fence、ledger revision、credential revision、截止时间 | 旧结果不提交、不释放新锁，保留可诊断原因 |
| 市场身份 | venue/nativeSymbol/canonical base、quote/settlement、乘数/单位 | 不猜等价，不以展示名改写执行身份 |
| 读取结果 | 数据、源时间、成功/缓存/缺失、完整性与版本 | 不把读取失败当空仓，不把截断当完整 |
| 部署目标 | 正式 commit/tag/manifest 摘要、scope、实际回执 | 不匹配明确失败或推迟，latest 变化不能静默换目标 |
| 研究数据 | 单位、schema、输入摘要、决策/报价时间、模型与费用版本 | 含混输入拒绝；缺失结果明确标记，不生成假零值 |

新外部调用必须明确超时、重试上限和总预算；缓存明确失效条件。公共 helper 只在至少两条已确认同语义路径需要时抽取。每批保留旧读兼容和必要迁移，先定义真实入口验收，再实施。

## 4 容量与后续架构的进入条件

| 后续选择 | 进入条件 | 暂不进入的原因 |
| --- | --- | --- |
| 事务事件/outbox | 至少一个明确跨进程消费者需要可重放、一致水位，已有本地事务写源 | 局部 SSE 快照重连不等于持久事件，也不要求为所有页面先建总线 |
| PostgreSQL | 索引/短事务/查询范围优化后仍有持续写争用，或确需跨主机权威写源 | #90/#179 已用部分索引解决已测的全量解析，换库不自动带来收益 |
| 新进程/服务拆分 | 观察到隔离收益、独立扩缩需求与故障边界 | 现有模块和 API/运行时已有隔离 |
| 多实例 | 共享控制状态、任务归属、旧写者隔离与部署证据齐全，容量测量支持 | 双槽切换不等于任意多主或跨主机运行 |
| 更换语言/算法栈 | 剩余 CPU 热点经 profile 确认，局部替换能保留可验证语义 | 未取得支持整仓重写的证据 |

服务器状态页（PR #144）和数据面卡顿卡片（PR #197）已能在用户环境读到进程资源与 event-loop 延迟，但尚未汇总成基线。生产 SLO、RPO/RTO、数据库/WAL 增长、恢复材料异地取回仍需用户环境的脱敏证据；避免新增高基数账户标签或原始凭据日志。

v0.1 的两项产品选择已定：ADL 按合约独立推进（#91，PR #188）；流水线只部署本轮正式提交，不一致时推迟（#94，PR #114）。目前没有待用户决定的事项。

关闭问题单仍须对应修复验收，不因 CI 绿色或代码合入直接结案。正式发布沿用仓库流程，服务器仍由用户自行更新，除非当次另有部署授权。本稿不替代现有权威规则，也不推进历史复盘检查点。下一版应填入安全扫描结果与生产基线，并在架构实施基线更新后删去第 5 节第 3 项。
