# 工作台与原项目的界面约定

适用于 ASTER 5X、Market Monitor、Asset Ledger，以及后续接入的项目。样式由每个项目自己的前端维护，使用现有组件和图表库，不依赖工作台跨域注入或新增共享运行时。

## 布局

- 工作台负责左侧项目导航；原项目使用“名称与操作顶栏 → 横向功能导航 → 页面内容”。独立访问原项目时仍保留全部功能、刷新和退出入口。
- 顶栏约 72px，内容最大宽度 1560px，桌面内边距 32px，手机 16px。窄屏功能导航可横向滚动，表格在自身容器内滚动。
- 页面标题 24–26px，区域标题 16px，正文与控件 14–16px。使用 `Segoe UI`、`Microsoft YaHei`、`sans-serif`；数值使用等宽数字，不用整页等宽字体。
- 面板圆角 10px，弹窗 12px，普通按钮至少 40px 高。主操作使用实心青绿，其他操作使用白底边框或文字样式。

## 颜色

| 角色 | 色值 |
| --- | --- |
| 页面底色 / 内容面板 | `#f4f7fa` / `#ffffff` |
| 正文 / 次级文字 | `#20334c` / `#66748a` |
| 边框 | `#e0e7ef` |
| 主操作 / 悬停 | `#087f83` / `#066b70` |
| 导航选中背景 | `#e7f4f3` |
| 成功 / 正值 | `#147d64` |
| 危险操作 / 负值 | `#c64b55` |
| 告警 / 旧值 / 数据不完整 | `#9a6718` |
| 对比曲线 | `#356dc4` |
| 参考曲线 | `#65758c` |

保持浅色主题，不随操作系统自动变为深色。工作台侧栏使用深蓝色，项目内容不再添加第二层深色侧栏。

## 数据与交互

颜色只辅助识别。正负号、状态文字、更新时间、单位、图例和曲线虚实线继续显示；过期和缺失数据不得仅因换主题而看起来正常。保留原有计算、采样、坐标范围、风险限制和操作确认。

页面状态和数据流不随视觉统一而重构。市场切换、账户切换、账本 hash 导航、轮询与流式连接继续由各项目原实现管理。弹窗、表格、输入框及键盘焦点都需检查，手机页面不能出现整体横向溢出。

验收使用本地隔离的示例或模拟数据，覆盖宽屏、嵌入工作台和窄屏。Monitor 的原油页面有独立 Shadow DOM，必须同时维护其样式和图表颜色。
