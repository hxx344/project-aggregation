# 代码审查清单

配套 [审查标准](code-review-standard.md)。每条只回答「是/否/不适用」，并在 PR 或提交信息里留痕。**勾选不等于已验证**——涉及运行的部分必须写出命令与结果。

## 通用（每次改动）

- [ ] 改动只做一件事；重构与行为变更已分开
- [ ] `pnpm run check` 通过；涉及测试已实际运行并记录结果
- [ ] 新增分支有对应的失败场景测试，或说明为何不需要
- [ ] 没有调试残留、临时开关、注释掉的代码、被放宽的断言
- [ ] 没有夹带无关文件（格式化、重命名、生成物）
- [ ] 文档/注释与实际行为一致；没有把未修问题写成已修
- [ ] 回滚方式明确（R2 以上）

## 数据与计算

- [ ] 单位、精度、计价币种与目标一致（L016、L038）
- [ ] 标的/合约/账户身份全程可区分（L020、L027）
- [ ] 分子分母口径一致（L059）
- [ ] 时间窗口与分页覆盖声称的范围（L045、L047）
- [ ] 聚合限定了可聚合类型（L025）
- [ ] 事件后的读取能**证明**已反映该事件（L054）

## 状态、缓存与调度

- [ ] 缓存读取语义 = 当前计算语义，失效条件覆盖更新（L002）
- [ ] 调度周期没有被当作数据有效期（L040、L049）
- [ ] 页面状态没有被当作服务端连接状态（L058）
- [ ] 主动断开/停止后，保留与停止老化的字段已区分（L056）
- [ ] 恢复事件已合并，且不误取消本轮新请求（L003）
- [ ] 配置迁移不会用同值写入覆盖新模型（L042）

## 失败路径

- [ ] 超时、重试次数、退避、总时限有界（L013、L050）
- [ ] 部分失败时状态一致，重试幂等
- [ ] 失败/拒绝后前端提交标记已解除（L029）
- [ ] 异步清理顺序正确（L037）
- [ ] 断开/重连/卸载时定时器与订阅已清理，不重复启动轮询链

## 安全与资金边界（R3 必查）

- [ ] 特权操作输入只来自可信来源（L009）
- [ ] 凭据/token 不进入日志、错误信息、响应、前端包（L014）
- [ ] 停服或批量操作前的前置条件有完整且新鲜的依据（L008）
- [ ] 新增接口的鉴权与同类接口一致，含只读接口
- [ ] 失败默认拒绝，不默认放行
- [ ] 有独立审查记录与回滚方案

## 交付与部署

- [ ] 在用户实际入口验证过，不只在开发服务器或测试桩（L017）
- [ ] 构建/安装实际读取的输入与提交内容一致（L011）
- [ ] 发布身份一致（L015）
- [ ] 安装/更新脚本覆盖真实入口、临时目录、冻结安装与缓存目录（L018、L019、L032、L055）
- [ ] 长操作可观测：进度、续传、失败诊断（L030、L036）

## 性能与优化

- [ ] 有参考结果与规模检查，不只是"感觉更快"（L006）
- [ ] 优化的前提（输入稳定性、必要更新）已确认（L007）
- [ ] 没有用缓存换取过期数据

## 前端与样式

- [ ] 子面板样式不改变公共页面宽度/布局（L021）
- [ ] 时间戳/时钟字段没有套用不适用场景的整数约束（L022）
- [ ] 加载、空态、错误态都有对应展示

## 按改动类型追加

| 类型 | 追加检查 |
| --- | --- |
| 模块拆分/改名 | 所有调用方已迁移；`modules/` 与 `server/modules/` 引用一致（L005） |
| 依赖升级 | 影响面、锁文件、CI 与部署安装路径、回滚方式 |
| 数据库/迁移 | 迁移可重复执行、失败可恢复、旧数据兼容（L010） |
| 部署/更新器 | 真实安装、激活、回滚、无操作更新（L034、L036） |
| 仅文档 | 结论准确、引用路径存在、未复制规则正文 |
