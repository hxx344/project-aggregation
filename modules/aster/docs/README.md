# Aster 5x 模块文档

双子账户配对支持黄金 `XAUUSD1` 和白银 `XAGUSD1`。从工作台进入 Aster 5x，在新建配对组时选择标的；A 固定做多、B 固定做空，保存后保持暂停。已有组也可在“配对组设置”中修改交易标的，无需删除或重新创建配对组；组标识、两个成员及方向保持不变。

更换标的前先暂停配对组，处理两侧所有持仓、挂单及待核对订单或划转；如果组内还记录旧底仓，先完成空仓核对。保存时服务端重新核验两侧完全空仓且没有挂单，失败时保留原组和原标的。仍在跟踪的人工归档订单需要继续核对，不能通过更换标的绕过。保存成功后继续保持暂停，原金额、策略和保证金设置保留，核对新标的参数后再启动。

切换会归档旧运行状态，原始成交与执行历史继续保留；成本按当前标的分别显示，切回原标的仍可查看对应成本。同一配对组的当日成交额度和未确认成交限制跨标的累计，不会因切换而清零。

普通开仓、独立循环、持仓核验、订单恢复和净持仓展示均使用本组标的。原黄金配对组无需迁移，缺省标的仍为黄金。单账户策略的默认品种、普通 `all` 范围和迁移目标保持原有配置。

配对白名单由 [`pair_symbols.py`](../trading/pair_symbols.py) 维护，前端通过已登录的 `GET /api/pairs/supported-symbols` 读取。普通开仓沿用每侧最低 500 USD1、默认单批 1000 USD1 和现有价差限制；实际数量步长、最小数量及最小名义金额仍取交易所规则。循环参数需要按所选品种的实际价差配置，切换标的不自动放宽风控。

容量中继协议和缓存按标的隔离；调度和行情订阅也必须包含活跃配对组的标的。内置中继服务的新配置默认订阅 `XAUUSD1,XAGUSD1`，已有显式 `ASTER_RELAY_SYMBOLS` 不会被覆盖。若外部中继仍只提供黄金，需要在该中继的现有配置中加入 `XAGUSD1` 后更新服务。白银额度缺失或过期时只等待白银数据，不借用黄金额度。

新服务器安装独立中继、接入现有工作台及检查数据状态，见[额度中继部署说明](../../../docs/aster-relay.md)。中继安装器与连接导入工具均由当前工作台仓库发布。

已保存的白银配对组也会在启动时核验双向持仓、两侧实际杠杆、真实账户身份和挂单。目录中的“支持”表示软件支持，不代表已替用户完成实盘验证。所有新增回归使用隔离账户和模拟成交；本次未发送实盘订单或划转。
